# Вечерний сеанс

Личный гид по фильмам и сериалам 2021–2026: каталог по году, стране и жанру, рейтинги, где смотреть в России и рекомендации под вкусы. Требования — в [PRD.md](PRD.md).

Сайт: https://yurik1959.github.io/vecherniy-seans/

## Файлы

- `data.js` — встроенный каталог (14 фильмов и 20 сериалов)
- `body.html` — разметка
- `style.css` — стили, светлая и тёмная темы
- `app.js` — логика: каталог, рекомендации, анкета, хранение, «Подбор от Claude»
- `index.html` — собранная самостоятельная страница (GitHub Pages)
- `page.html` — фрагмент для публикации в Claude как Artifact
- `build.sh` — собирает `index.html`, `page.html` и `preview/index.html`

## Сборка

```sh
./build.sh
```

## Два способа запуска

- **Artifact в Claude** (`page.html`, возможности `db`, `user`, `sample`): оценки и профиль сохраняются в аккаунте, работают «Подбор от Claude» и пополнение каталога через коллекцию `extra`.
- **GitHub Pages** (`index.html`): работает без возможностей Claude, оценки и профиль хранятся только в браузере.

Рейтинги и площадки приблизительны и требуют сверки (PRD, раздел 6.3).
